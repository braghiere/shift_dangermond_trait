Nimbus Sans (OTF) — the sans-serif font used in all generated figures of this paper.

Nimbus Sans is URW's free, metric-compatible clone of Helvetica (part of the
URW base35 core fonts). Redistributed under the AGPLv3 + font exception, so it
is free to install and use.

Purpose: install these on any machine (e.g., for editing Figure 1 in PowerPoint)
so the study-area map uses the same font family as Figures 2-10.

macOS install: select the four .otf files -> right-click -> Open -> "Install Font"
  (or open Font Book and drag them in). They then appear as "Nimbus Sans" in
  PowerPoint. Set every text box in the figure to Nimbus Sans, then export to PDF
  with "Best for printing" so the font embeds.

Equivalent alternative: Arial (or Helvetica) is metric-compatible with Nimbus
Sans and visually indistinguishable at print size; either is an acceptable,
universally-embeddable substitute if you prefer not to install a new font.

Files:
  NimbusSans-Regular.otf
  NimbusSans-Bold.otf
  NimbusSans-Italic.otf
  NimbusSans-BoldItalic.otf
Source: /usr/share/fonts/urw-base35/  (Artifex urw-base35-fonts)
